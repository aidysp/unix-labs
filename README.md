## 🛠️ Как клонировать репозиторий и переключаться между работами

1. **Клонировать репозиторий со всеми ветками:**
   ```bash
   git clone https://github.com
   cd unix-labs
   ```

2. **Посмотреть список всех доступных лабораторных (веток):**
   ```bash
   git branch -a
   ```

3. **Переключиться на интересующую лабораторную работу (например, первую):**
   ```bash
   git checkout lab1
   ```
