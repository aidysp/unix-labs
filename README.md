## Описание реализации
Написан переносимый скрипт `build.sh`, совместимый со стандартом POSIX Shell (`#!/bin/sh`), который автоматизирует сборку файлов (C/C++ и документов TeX). 

Ключевые особенности скрипта:
1. **Изоляция сборки:** Компиляция выполняется внутри изолированного временного каталога, создаваемого утилитой `mktemp -d`, что предотвращает замусоривание рабочей директории промежуточными файлами (например, `.o`, `.aux`, `.log`).
2. **Безопасная очистка (Обработка сигналов):** Использована встроенная команда `trap`. При любом исходе работы скрипта (нормальное завершение `EXIT` или прерывание процесса сигналами `INT`, `TERM`, `HUP` и др.) временный каталог гарантированно удаляется со всем содержимым.
3. **Парсинг метаданных (`grep` + `sed`):** Скрипт автоматически сканирует исходный файл, находит управляющий комментарий `Output: имя_файла` и использует выделенное имя для финального исполняемого файла.
4. **Информативные коды возврата:** Каждая ошибка (отсутствие аргументов, файла, метки или сбой компиляции) завершает работу со своим уникальным кодом `exit` (от 1 до 7), направляя текст ошибок строго в поток `stderr` (`>&2`).

## Инструкция по запуску

1. Сделать скрипт исполняемым:
   ```bash
   chmod +x build.sh
   ```

2. Пример тестового файла (`main.c`):
   ```c
   // Output: my_cool_program
   #include <stdio.h>
   int main() {
       printf("Hello, TSU!\n");
       return 0;
   }
   ```

3. Запуск сборки:
   ```bash
   ./build.sh main.c
   ```
